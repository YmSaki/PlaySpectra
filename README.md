# VR-MCP

VRアプリケーション開発時に、AIエージェントが「ブラウザに対する Playwright」のように
VRアプリを操作・観察するための MCP サーバー。

- VRコントローラー（トリガー/グリップ/スティック/ボタン）と HMD の姿勢をプログラム的に注入
- 画面の状況を画像として取得（既定は利き目カラー画像+深度マップ、生の左右ステレオも選択可能）
- エンジン非依存（Unity / Unreal / ネイティブ OpenXR アプリ）
- 実機 HMD 不要の完全ヘッドレス/シミュレーション動作

設計の詳細と実装順序は `.claude/` 配下のプランを参照。詳細なセットアップ手順・
Unity/Unreal での利用方法は実装完了後に本ファイルへ記載する（task #10）。

## 構成

```
mcp/            TypeScript MCP サーバー
layer/          C++ OpenXR API レイヤー (CMake, MinGW)
scripts/        セットアップ・起動スクリプト
third_party/    FetchContent / 外部ランタイムの取得先 (非コミット)
```
